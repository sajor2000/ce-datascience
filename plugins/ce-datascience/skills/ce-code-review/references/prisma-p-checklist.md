# PRISMA-P 2015 Checklist for Systematic Review Protocols

PRISMA-P (Preferred Reporting Items for Systematic review and Meta-Analysis Protocols) 2015: 17 numbered items (26 rows counting lettered sub-items) in three sections. Item numbers and paraphrased wording follow Table 3 of the statement; review cues are added by this plugin. Use it for review protocols; completed reviews use PRISMA 2020.

**Current primary reference:** Moher D, Shamseer L, Clarke M, et al. Preferred reporting items for systematic review and meta-analysis protocols (PRISMA-P) 2015 statement. Syst Rev. 2015;4:1. doi:10.1186/2046-4053-4-1. PMID: 25554246. PMCID: PMC4320440.

**Explanation and elaboration:** Shamseer L, Moher D, Clarke M, et al. PRISMA-P 2015: elaboration and explanation. BMJ. 2015;350:g7647. doi:10.1136/bmj.g7647. PMID: 25555855.

**Verified against:** PRISMA-P Table 3 in the PMC full text, https://pmc.ncbi.nlm.nih.gov/articles/PMC4320440/.

## Administrative information

| Item | Description |
|---|---|
| 1a | Identify the report as a protocol of a systematic review |
| 1b | If the protocol is for an update of a previous review, identify it as such |
| 2 | If registered, registry name (e.g., PROSPERO) and registration number |
| 3a | Name, affiliation, and e-mail of all protocol authors; mailing address of the corresponding author |
| 3b | Contributions of protocol authors and the guarantor of the review |
| 4 | If an amendment, identify it and list changes; otherwise state the plan for documenting important amendments |
| 5a | Sources of financial or other support |
| 5b | Name of the review funder and/or sponsor |
| 5c | Roles of funders, sponsors, and/or institutions in developing the protocol |

## Introduction

| Item | Description |
|---|---|
| 6 | Rationale for the review in the context of what is already known |
| 7 | Explicit statement of the review question(s) with reference to participants, interventions, comparators, and outcomes (PICO) |

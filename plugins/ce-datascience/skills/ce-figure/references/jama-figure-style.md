# JAMA Figure Style

Use this profile for clinical manuscript figures unless the user selects another journal profile.

The values below are this plugin's profile defaults, not journal text. JAMA Network's instructions for authors (https://jamanetwork.com/journals/jama/pages/instructions-for-authors) state Arial, 12 pt bold figure titles, 10 pt text within figures, and 8 pt legends, list vector formats (.eps, .pdf, .ai, .emf) for graphs at revision, and do not list PNG or SVG. Confirm the live instructions for the named submission target before export; they override this profile.

- Arial or Helvetica font.
- Minimum 8 pt text across labels, legends, annotations, and footnotes.
- Titles 10-12 pt bold.
- Axis labels 9-10 pt.
- Tick labels 8-9 pt.
- Legends outside the data region or in clear whitespace.
- No text overlap.
- Export main figures as separate publication files when preparing a journal package; prefer a vector format (PDF or EPS) for graphs.
- Preserve source data and source code with the figure manifest.

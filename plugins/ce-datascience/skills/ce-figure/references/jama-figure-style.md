# JAMA Figure Style

Use this profile for clinical manuscript figures unless the user selects another journal profile.

- Arial or Helvetica font.
- Minimum 8 pt text across labels, legends, annotations, and footnotes.
- Titles 10-12 pt bold.
- Axis labels 9-10 pt.
- Tick labels 8-9 pt.
- Legends outside the data region or in clear whitespace.
- No text overlap.
- Export main figures as separate publication files when preparing a journal package.
- Preserve source data and source code with the figure manifest.

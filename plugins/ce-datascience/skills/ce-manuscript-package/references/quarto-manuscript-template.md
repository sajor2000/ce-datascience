# Quarto Manuscript Template

Use Quarto when the project already has a Quarto stack profile or when the user asks for multi-format manuscript output.

Recommended files:

- `manuscript/manuscript.qmd`
- `manuscript/_quarto.yml`
- `manuscript/tables/`
- `manuscript/figures/`
- `manuscript/supplement/`
- `manuscript/checklists/`

The manuscript source should link to generated tables and figures rather than duplicating analysis output by hand.

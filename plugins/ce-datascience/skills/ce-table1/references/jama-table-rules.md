# JAMA Table Rules

Use these rules when the selected style profile is `jama`. They summarize JAMA Network's instructions for authors (https://jamanetwork.com/journals/jama/pages/instructions-for-authors; also listed under `sources` in `references/journal-style-profiles.yaml`); confirm the live instructions for the named submission target, which override this summary.

- Report frequency data as `No. (%)`.
- Include numerator and denominator whenever possible.
- Avoid decimal percentages when sample size is under 100.
- Comparisons should read across columns.
- Do not duplicate the same primary outcome data in both a table and figure unless the manuscript requires it.
- Tables should have descriptive titles, clear footnotes, and expanded abbreviations.

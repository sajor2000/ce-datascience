# Detailed setup survey

Use this only after the user explicitly selects **Full survey**. Ask one
question at a time and skip fields already confirmed in the review card.

1. Primary language and IDE
2. Storage layer and verified connection acceptance
3. Libraries and environment manager for the selected language only
4. Reporting format
5. Local extract/cache root only when needed
6. Blinding state and reporting checklist only for an active study workflow

Never ask R package questions for a Python-only profile or Python package
questions for an R-only profile. Treat `both` as a deliberate user choice or
strong evidence of active R and Python analysis, not as the fallback for an
unknown repository.

# Fonts

Latin subsets served with the documentation site, from
[Fontsource](https://fontsource.org) 5.2.5. Both families are licensed under the
SIL Open Font License 1.1.

| File | Family | Source |
|---|---|---|
| `source-serif-4-600.woff2` | Source Serif 4 Semibold | [adobe-fonts/source-serif](https://github.com/adobe-fonts/source-serif) |
| `ibm-plex-sans-{400,500,600}.woff2` | IBM Plex Sans | [IBM/plex](https://github.com/IBM/plex) |
| `ibm-plex-mono-{400,500}.woff2` | IBM Plex Mono | [IBM/plex](https://github.com/IBM/plex) |

See `docs/brand/brand.md` for how each face is used.
